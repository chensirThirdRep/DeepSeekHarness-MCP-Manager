# mcp-server-management Specification (delta)

## ADDED Requirements

### Requirement: MCP 管理页的编辑表单在目标行内联展开

设置页在用户点击某一行的「编辑」时，MUST 把编辑表单渲染在该行卡片内部、位于该行信息与操作按钮之下；MUST NOT 只把编辑表单渲染在列表上方的固定位置。表单展开时，页面 MUST 把该行滚入可视区。编辑中的行 MUST 与其它行有可辨识的视觉差异，且内联表单 MUST NOT 与该行形成重复的外框。

保存成功后表单 MUST 收起、该行 MUST 回复普通外观并显示保存后的值；取消 MUST 同样收起且不写入任何变更。

同一时刻 MUST 只存在一个表单：编辑表单展开期间，其它行的「编辑 / 启用 / 禁用 / 重启 / 删除」按钮与列表上方的「+ 新增 MCP 服务」入口 MUST 处于禁用状态。

新增表单不受本条约束：没有对应行可挂载时，新增表单 MUST 保留在列表上方展开。

#### Scenario: 编辑列表靠后的条目

- **WHEN** MCP 管理页列出 6 台服务，视口只能看到前 4 台，用户滚动到底部并点击第 6 台的「编辑」
- **THEN** 编辑表单出现在第 6 台卡片的正下方
- **AND** 页面不会跳回列表顶部，用户在当前位置即可编辑并保存

#### Scenario: 展开时滚动到该行

- **WHEN** 用户点击某一行「编辑」，且该行当前只有部分可见
- **THEN** 页面以就近方式滚动，使该行与展开的表单进入可视区

#### Scenario: 编辑中的行可辨识

- **WHEN** 某行的编辑表单处于展开状态
- **THEN** 该行带高亮边框
- **AND** 内联表单不再重复绘制自身外框（字段与标题仍完整可见）

#### Scenario: 保存后收起并显示新值

- **WHEN** 用户在行内表单修改字段（例如把工具调用超时改为 300 秒）并点击「保存」
- **THEN** 表单收起、该行恢复普通外观
- **AND** 该行显示保存后的新值（工具调用超时为 `300s`），视口位置不跳回列表顶部

#### Scenario: 取消不写入

- **WHEN** 用户在行内表单修改字段后点击「取消」
- **THEN** 表单收起、该行显示修改前的值
- **AND** 补丁文件的字节内容与操作前完全一致

#### Scenario: 编辑进行中其它操作被禁用

- **WHEN** 某一行的编辑表单处于展开且未保存状态
- **THEN** 其它行的「编辑 / 启用 / 禁用 / 重启 / 删除」按钮均为禁用状态
- **AND** 列表上方的「+ 新增 MCP 服务」入口同样为禁用状态

#### Scenario: 新增表单保持原位

- **WHEN** 用户点击「+ 新增 MCP 服务」
- **THEN** 新增表单仍在列表上方展开，列表为空时同样可用
